# 修复 v0.5.9 把 dat size 误判成 Win32 740

## 问题

- 用户用 v0.5.9 更新国际服 GGPK 时，价格已经生成 580 条并写出 `物价补丁.zip`。
- 随后更新器报“Python 无法以普通权限启动”，丢弃本次构建，游戏文件未写入。
- 根因是 `Test-Poe2PythonElevationFailure` 在全部 Python 输出里裸匹配 `740`，`dat size: 2724108 -> 2740570` 被误判。

## 修复

- 退出码 740 仍视为提权失败。
- 标准输出只匹配 elevation 英文短语，不再裸匹配数字 740。
- 异常文本才匹配 `error 740` / `Win32 740` 等错误上下文。

## 回归验证

- 新增 `test_python_elevation_detection_ignores_dat_size_false_positive`。
- 自动化：194 passed；本机 4 个 `Get-FileHash` 失败是 Codex PS7 模块路径污染 powershell.exe 的旧问题，与本次改动无关。
- 真实写入：
  - POE2 国际官方 GGPK `D:\poe2`：580 条，已写入并校验 3 个文件。
  - POE2 国服 WeGame Bundles2：635 条，已写入并校验 3 个文件。
  - POE1 国际 Steam Bundles2：已安装并通过读回校验。
  - POE1 国服 WeGame Bundles2：898 条，已安装并通过读回校验。
- 四个客户端日志均无 740 误判。
