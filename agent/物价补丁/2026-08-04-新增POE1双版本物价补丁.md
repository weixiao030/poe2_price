# 新增 POE1/POE2 双版本物价补丁

## 方案与可行性

- POE1 数据源可用：国际服使用 poe.ninja 的 POE1 赛季、通货交换和传奇接口；国服使用 `poecurrency.top/api/summary?version=1`，并以 poe.ninja 补齐缺失项目。
- POE1 与 POE2 的资源格式和价格单位不同，因此保留独立构建器、缓存、输出目录、还原包和脚本入口。POE1 使用混沌石/神圣石 C/D，POE2 继续使用 D/E。
- Steam/Epic/WeGame 使用 Bundles2，官方独立客户端使用 Content.ggpk；BundleExtractor 增加 GGPK 识别和批量提取命令后，三类客户端可以复用同一安装流程。

## 实现

- 新增 `poe_patch_profiles.ps1` 和 `price_patch_gui.ps1`，统一支持 POE1、POE2、自动识别、手动选择和最近目录保存。
- 新增 `build_poe1_price_patch.py`、`poe1_patch_common.ps1`、POE1 更新/还原脚本；POE1 BaseItemTypes 支持当前 374 字节布局，Words 支持传奇价格标注和清理。
- 更新发布 payload、加密载荷和自包含启动器；启动器保留旧 POE2 设置兼容，同时只在明确游戏目录时提前加锁，最终由版本脚本按真实目录互斥。
- 完成 Steam 与 WeGame `-NoInstall` 实测、物理还原演练、POE1 数据源和 GUI 回归测试；未修改真实游戏文件，也未推送远端。
