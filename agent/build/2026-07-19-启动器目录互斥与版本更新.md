# 启动器目录互斥与版本更新

## 改动

- `Poe2PatchLauncher` 在补丁不位于游戏根目录时读取最近确认的游戏目录，用于启动前互斥范围；PowerShell 入口在用户最终确认后再获取第二层真实游戏目录锁。
- 启动器忽略不存在或不含游戏包文件的旧设置，首次运行仍以补丁目录作用域启动并由脚本完成最终选择。
- 版本统一更新为 `v0.4.9.6`，同步项目版本、程序集版本、文件版本和信息版本。
- README 的内置 Python 说明同步到构建脚本实际使用的 `3.13.14`，不再继续显示旧 `3.10`。
- 使用文档生成器新增目录选择、国服 WeGame 名称、多客户端处理及还原选择说明，并为加长后的列表统一留出段落间距。
- 清除 WPS 模板 `List Bullet` 样式中的 `contextualSpacing`，避免 LibreOffice 把换行后的连续项目符号重叠到同一行；最终 5 页已逐页渲染检查。
- 发布脚本生成的简版说明同步改为“任意位置 + 自动/手动选择”，避免构建时重新写回“必须放在游戏根目录”的旧指引。
- 发布一致性测试新增还原脚本版本校验、还原 payload 同步检查和新版使用说明关键内容检查。

## 原因

启动器脚本位于随机临时目录且补丁文件夹现在允许放在任意位置，只按补丁目录加锁无法阻止不同副本同时修改同一游戏。两层互斥既保留启动阶段的防重复运行，也覆盖首次选择和跨补丁副本并发。
