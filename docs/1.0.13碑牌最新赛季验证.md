# v1.0.13 碑牌最新赛季验证

2026-09-28，根据用户要求，碑牌底材、暗金及词缀价格统一采用对应服务器的最新普通赛季。普通通货及其他传奇仍按界面选择的赛季获取。碑牌目录在每次构建时独立解析，行情请求与汇率使用同一明确赛季；不会将最新报价按历史赛季汇率显示。

国际服暗金碑牌改用独立的 `UniqueTablets` 最新赛季接口，普通传奇行情里的历史碑牌价格不再回填。国服整件市场与词缀市场共用最新国服赛季。目录或某个来源不可用时保留独立失败结果，不将普通物价的历史赛季冒充最新碑牌赛季。已有历史缓存按实际市场身份隔离，完整补丁缓存增加 `tablet-latest-v1` 标识。

本地验证使用此前从真实游戏提取的资源副本，普通价格固定选择 `Runes of Aldur` / `RunesofAldur`，碑牌访问实时接口。

国服有 1 组词缀没有可用行情；4 种暗金（疆域主宰、宏伟计划、无常因果、乐园幻象）的源站交易条件改为至少剩余 1 次，与当前整件校验规则的至少 5 次不同，因此保留无价。普通霸主底材没有普通报价，沿用已有规则选用可用稀有度报价。本次仅调整赛季来源，未放宽交易条件校验。国服汇率带过期标记，依现有策略采用同赛季有效汇率并记录时间。

新增 16 项回归覆盖两服碑牌开关组合、历史赛季与碑牌赛季隔离、汇率隔离、暗金历史价覆盖与清理，以及错误市场目录拒绝。原普通物价离线测试的模拟入口同步为最新赛季解析函数。Python 全量 545 项、桌面 54 项测试、类型检查、构建与引擎来源哈希校验通过。

包内 Python 与引擎完成国际服实时构建：普通价格仍为 Runes of Aldur，碑牌为 Forbidden Rites，8 类底材、9 种暗金、254 组词缀全部生成。NSIS 安装包提取后的 357 个文件逐项哈希一致，279 个引擎文件与清单、源码打包运行目录一致。

安装包：`desktop/dist/POE-Price-Patch-1.0.13-x64-Setup.exe`。

本地证据保存在 `verification/latest-tablet-season/`：两服 `source-*/result.json`、`packaged-international/result.json`、构建日志、Python 与桌面测试日志、`migration.log`、`installer-check.json`。本地验证阶段仅生成并验证安装包和补丁包，未安装到用户程序目录、未写入真实游戏。正式发布按 main CI、版本标签构建、ZOS 回读校验、GitHub Release 的顺序执行。
