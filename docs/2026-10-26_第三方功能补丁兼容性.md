# v1.0.21 第三方功能补丁兼容检查

2026-10-26，针对用户提供的 POE2 V8.4 原版字体 v3，以及“A大新版补丁”中的 POE1 V46.6、POE2 V8.4 两种字体版本，先在隔离副本上检查，随后使用真实打包桌面程序，在本机 POE1 国际服、POE2 国际服和 POE2 国服客户端执行更新、重复更新、资源读回及还原。未执行第三方安装器、批处理或游戏程序，未登录游戏检查界面。

## 已修复的问题

原版字体 v3 的 `_.index.bin` 外层可以正常解压，但内嵌路径池的第 51 至 335 块无法由当前 LibBundle3 解压。旧安装器生成价格后，会在安装阶段完整解析路径池，因而报 `Failed to decompress chunk with index: 51` 并回滚。这与行情获取无关。

`ResourcePatch.cs` 现在按资源 hash 验证和替换文件：

- 只替换已有资源时，原路径池及其附带数据逐字节保留。
- 新增碑牌资源时，在块边界追加路径；保持原有目录记录和不透明压缩块。可解压的不完整末块补齐后重压；原本不可解压的末块保留压缩字节。
- 新增路径沿用原路径池的压缩器。V8.4 使用 Hydra（12），不能直接混入默认 Mermaid（9）编码的块。
- 复用本工具已有目录时，只读取并验证该目录。实际目标资源损坏、自家目录损坏、路径冲突或提交前文件变化，仍然拒绝写入。
- 保留暂存、原记录核对、游戏进程保护、独占提交、安装后读回和失败还原。

这项修复使物价安装流程兼容该路径表；全量 `--list` 仍会遇到第三方原路径区的解压失败。未确认这些不可解压区段的产生原因。
