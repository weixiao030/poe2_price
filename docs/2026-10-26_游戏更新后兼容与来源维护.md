## 已修复的问题

### 国服整件碑牌使用其他币种时漏价

当前公开整件接口中，6 条有价报价改用 `annul`（剥离石）或 `chance`（机会石）。旧代码只接受原币种 E/C/D，导致这些报价被当成不可用；其中包括普通深渊、普通驱灵仪式、神庙碑牌及暗金乐园幻象。

本次保留通过服务器、最新碑牌赛季及有效性校验的全部汇率，在选定原币种样本后换算为既有 E/C/D 显示。原始币种、样本量和价格保留在报告中，不将不同币种样本合并计算中位数。没有有效汇率、异常中位数或交易条件不符时仍跳过；缓存保留原始分页响应，每次按当前同服赛季汇率重新解析。

同一份国服公开响应回放：修复前接受 26/33 条，修复后接受 32/33 条；唯一剩余项为普通霸主石板 `no_listings`。例如，1 剥离石按本次国服汇率显示 3.75C，2 剥离石显示 1.18D，15 机会石显示 2.04C，均截断小数。

### poe.ninja 分类审计误报

网页分类的 `title` 从字符串改为 `{id, message}` 多语言对象。审计已兼容两种结构；同时将实际由独立适配器使用的 `PrecursorTablets` 纳入分类及字段核验，避免误报其消失和 `lines.variant` 缺失。修复后实时发现 23 个分类，POE2 Ninja 审计状态恢复为 healthy，普通价格接口没有更换。

### 下载源维护

软件更新和 POE1 汉化移除 gh.llkk.cc、ghproxy.imciel.com、ghfile.geekertao.top：实测分别有连接失败、超时，以及清单失败/多 Range 超时/完整汉化包超时。保留 ghfast.top、gh-proxy.com、ghproxy.it、gh-proxy.org、ghproxy.net 五个国内镜像。软件更新继续以 ZOS 兜底，汉化继续以 GitHub 官方源兜底；官方元数据摘要、更新签名和完整文件哈希校验保持启用。

新增 `desktop/scripts/audit-download-sources.ts`，通过 `npm run audit:downloads -- --full` 重做只读检查。检查包括签名清单、安装包固定版本与 Range、blockmap、多 Range 的实际字节、完整 ZOS 安装包 SHA512、各汉化源的官方 SHA256，以及构建时 Python/.NET 各下载地址的固定 SHA256。

### 验证脚本维护

跨版本更新测试复用 npm 已安装的固定版本 Electron，避免测试夹具构建再次依赖 GitHub 下载。桌面测试增加退出超时、失败堆栈记录和仅清理本测试进程树的兜底，避免失败被清理阶段的无限等待掩盖。首轮取消检查后未正常结束，原始日志保留；复跑取消进程树及后续全部检查通过，未据此修改应用的任务退出保护。
