# v1.0.18 空数据赛季过滤

2026-10-12（香港时间）。

获取 POE1/POE2 国服赛季列表后，按每个赛季的实际 summary 接口检查数据。当前赛季使用数字版本且省略 season，历史赛季携带原始名称。仅合法的空数组，或所有分类的 items 均为空数组，标记为 `PriceDataStatus=empty`；有条目为 available，网络错误、HTTP 错误、空响应和未知结构均为 unknown。旧报价或零报价不等同于没有数据。

桌面下拉框只过滤 empty。完整目录保留原先的 IsCurrent 与来源标识，避免当前赛季没有数据时把历史赛季误当成最新。固定选择已确认空数据时给出提示，不自动切季；重新刷新有数据后恢复显示。目录缓存保留三态，刷新失败回退时恢复 unknown，国服探测设置有限超时和总预算。

更新说明按用户原文加入：国服当前永久服数据在**RunesofAldur**赛季。
