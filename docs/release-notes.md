# POE 物价补丁 v1.0.2

POE2 岛屿传言在地图名前追加评级，例如 `坠落的星辰……(S级天陨荒原/八孔遗物)`。国际服与国服使用同一评级，保留各自语言的原传言、地图名和奖励提示。

- S 级：天陨荒原（星辰），附带八孔遗物提示。
- A 级：死水盆地、乱石半岛、笼葱海岛、凛风悬崖。
- B 级：贫瘠环礁、掘尸遗迹、脱落沟壑、牧野荒原、褪色浅滩、焦灼小岛。
- C 级：青玉群岛、蔓生丛林、恸哭悬崖、静谧神庙、无名之岛。
- 不评级：颠沛领域、纯净乐园、千裂泽、顿悟时刻。

修复国服“坠落的星辰”未匹配到八孔遗物提示的问题，并增加按地图位置的兜底；修正繁体提示中的“奧爾羅斯”。旧提示可直接升级，重复更新不会叠加评级，关闭功能后可正常清理还原。

继续使用 Windows x64 Setup 安装版。1.0.0 及以上版本可在“检查更新”中直接升级；0.x 用户运行本次 Setup。升级后关闭游戏，开启岛屿传言提示并执行一次物价更新，也可选择“仅岛屿传言提示”应用本次修改。
