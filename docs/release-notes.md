POE 物价补丁 v0.8.6

- 修复 v0.8.5 碑牌层未能实际安装的问题：GGPK 正确提取模板，安装器支持新增独立资源及索引路径，安装后逐项读回验证。
- 8 类碑牌词缀按具体数值范围匹配市场报价，修复描述文件控制字符、稀有度文字匹配及 Divine / Exalted 换算。
- 魔法和稀有碑牌共用完整词缀标价规则，各个有数据的词缀分别显示价格；功能默认随通货更新，不新增界面说明框。原岛屿传言开关与默认开启行为保留。
- 接入 poe.ninja 先行者碑牌价格，在剩余使用次数下分列普通、魔法、稀有底材参考价。词缀报价仅供参考，不能相加作为整件估价。
- 碑牌仍属于 POE2「通货与更新」，无需额外模块。词缀 API 和 poe.ninja 独立重试和跳过，部分失败会记录缺失来源，其他更新继续运行。
- 修复关闭碑牌、缓存回退和还原时残留旧引用的问题，同时清理中文和英文基础表中的已知实验模板，避免固定 `2D` 残留。
- 保留现有通货、传奇、岛屿提示、国服 OCR 报价校验、赛季选择、每小时更新及一键汉化功能。

升级后请关闭游戏并执行一次物价更新。支持 Windows 10/11 x64，提供 Setup 安装版和完整文件夹免安装 ZIP，均内置运行环境。免安装版须完整解压后运行 `物价补丁.exe`，保留配套 DLL 和 resources 文件夹。发行包未配置代码签名；项目许可及非商业条款不变。
