# POE 物价补丁 v1.0.1

新增 POE2 国服碑牌词缀价格。魔法与稀有分别取价，使用国服独立赛季、交易查询和汇率；支持接口已校验的实时行情，缺少报价的词缀保留原文。国服与国际服缓存独立，不用国际服词缀报价替代国服价格。

每次启动会在后台检测软件更新。发现新版后，右上角显示约 3 秒的小提示，悬停或键盘聚焦时暂停消失，不打断当前操作。可点“查看更新”进入更新页，或选择“本次更新不再提醒”；忽略只针对本次版本，后续新版本仍会提示，手动检查始终可用。不会自动下载或安装。

继续使用 Windows x64 Setup 安装版。1.0.0 用户可在“检查更新”中直接升级；0.x 用户运行本次 Setup。现有设置和游戏还原备份保留，软件升级本身不写游戏文件。升级后关闭游戏并执行一次物价更新以应用国服碑牌词缀价格。
