POE 物价补丁 0.7.4：修复每小时自动更新被旧版本自动关闭的问题。

- 还原补丁、任务成功、失败或跳过均保留自动更新开关和最近成功配置。
- 修改背景、主题等设置不再重置已有的每小时倒计时。
- 执行任务期间也可以手动关闭自动更新；关闭后不会再安排下一轮。
- 旧版本没有记录“用户是否手动关闭”的配置，会在首次启动时仅迁移一次：存在有效成功配置且开关被旧逻辑关闭时恢复开启；以后完全以用户手动操作为准。
- 重新打开应用会恢复已开启的自动更新；手动关闭状态也会持久保存。

已通过调度行为回归、真实 Electron 界面及开启/关闭状态重启验证。价格、DAT、汉化和还原引擎保持不变。

Windows 10/11 x64。Setup 为安装版，Portable 为免安装版，均包含运行环境。应用运行或驻留托盘时执行每小时任务；彻底退出后会在下次启动恢复调度。首次使用需要成功手动更新一次以保存有效配置。
