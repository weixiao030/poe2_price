POE 物价补丁 v0.8.5

- POE2 通货更新范围新增碑牌词缀标价：从自定义碑牌报价 API 获取词缀价格，并用 poe.ninja `PrecursorTablets` 目录校验先行者碑牌数据。
- 碑牌词缀按现有 `D/E` 价格格式写入独立 `.it` / `.csd` 资源，正面词缀追加紧贴原文的价格标记，负面词缀保持原样。
- 碑牌接口沿用请求重试；接口、模板或匹配失败时只跳过碑牌层并记录 `tablet_affixes.status=skipped`，通货、传奇和岛屿传言流程继续执行。
- 优化 POE1 / POE2 国服 OCR 报价校验，继续使用普通汇总接口，本地计算，无需 Token 或额外操作。
- 分侧结合历史均价、上一笔报价识别双边错价和单边极端值，避免重复字段重复计票；当前报价不可用时采用有依据的历史估值。
- 修复 D 单位绕过校验、神圣石单边异常污染汇率及派生 E 价格覆盖问题；国服 D/E、D/C 换算不借用国际汇率。
- 正常跨位数涨跌不再仅因网站错误标记被回退；小数点修正需要报价依据，持续宽价差不再一律取低价。
- 国际价格仅补缺和记录差异，不覆盖已有国服价格；日志可查看异常处理、历史回退和宽价差原因。
- 保留自动跟随最新赛季、手动固定选择、每小时更新、独立“一键汉化 POE1”、托盘、还原及游戏运行保护。
- 继续提供 Setup 安装版和完整文件夹免安装 ZIP（`POE-Price-Patch-0.8.5-x64-NoInstall.zip`）。

汇总数据中的当前价与全部历史价同时错误时仍可能漏判；真实行情突变可能暂时采用历史估值。升级后请关闭游戏并执行一次物价更新，以应用新的价格校验。

Windows 10/11 x64。两种发行包均内置运行环境。免安装版须完整解压到一个文件夹，保留 `物价补丁.exe`、DLL、`resources` 等配套文件，不要直接在压缩包内运行或单独移动 EXE。每小时自动更新需先成功手动更新一次，仅手动关闭才停用；应用彻底退出后暂停，下次启动恢复。发行包未配置项目代码签名。项目使用许可及非商业条款不变。
