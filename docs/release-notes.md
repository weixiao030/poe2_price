POE 物价补丁 v0.9.2

- 修复内置 Python 校验器找不到本地模块，导致新补丁被误报为 BaseItemTypes 结构不兼容的问题。
- 保留碑牌标价所需的 Mods、Stats、Tags 提取文件，避免构建前被清理。
- 校验失败显示实际原因；碑牌报价不完整时跳过该层，继续生成其他价格补丁。
- 桌面界面和更新、还原、汉化工具的版本标识统一为 0.9.2。

- 更新失败即使已成功回退，也会返回失败状态；回退失败保留恢复副本。
- POE1 真实还原包绑定官方底板，拒绝使用过期索引；汉化镜像载荷只信任独立官方摘要。
- 软件升级在预提交阶段失败时重新打开旧版；操作确认绑定展示时的目录和选项。
- 中文同名物品通过英文身份消歧；无法可靠匹配时跳过报价。
- POE2 还原保留已有英文干净基线，重复更新后可恢复原始资源字节；官方结构或英文名称变化时刷新基线。

包含以下功能：

- 碑牌词缀分别使用魔法、稀有挂牌样本的中位价。价格接近时合并，其余按从低到高显示，不增加品质标签；不再统一套用稀有价。
- E/C/D 根据汇率、报价习惯和可读性动态选择；价格差的合并阈值随全体有效碑牌行情从 20% 平滑变化至 10%，不写死 D/C 金额。
- 从当前游戏 Mods/Stats/Tags 精确绑定底材与词缀；两品质查询范围不同的条目明确跳过，避免误标。
- 左侧第四项新增“检查更新”，显示当前更新说明、免费声明、作者赞赏码与聊天/bug反馈群:168887742。紧凑窗口下说明独立滚动，赞赏码和更新按钮保持可见。
- 支持 ZOS 等 HTTPS 目录发布签名更新包。优先下载当前版本适用的增量文件包，校验后自动重启安装；保留更新备份，失败自动尝试回退。

客户端内置公开 HTTPS 下载地址，上传配置、AK/SK 和签名私钥不随软件或仓库分发。发布者操作步骤见[软件增量更新与 ZOS 发布](软件增量更新与ZOS发布.md)。0.8.8 及更早版本，以及未包含更新地址的旧构建，需要首次手动升级；带正确下载地址的版本才能发现后续更新。

支持 Windows 10/11 x64，提供 Setup 安装版和完整文件夹免安装 ZIP，均内置运行环境。免安装版须完整解压后运行 `物价补丁.exe`。升级软件后，关闭游戏执行一次物价更新即可刷新价签。报价来自低价端挂牌样本的中位数，不是成交价或全市场中位数。项目许可及非商业条款不变。
