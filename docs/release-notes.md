POE 物价补丁 0.8.1：补齐世界地图规划交互与后台路线状态。

- 新增 POE2 国际服专属世界地图，支持节点搜索、当前位置和路线规划，不与物价补丁页面混用。
- 游戏内透明覆盖层默认显示节点编号、地图名称及连接线、路线方向；平时鼠标穿透、不抢焦点。支持游戏内点选起点，选择结束、右键取消或超时后恢复穿透。
- 搜索结果显示距离及相对坐标、近到远排序，分页浏览全部匹配项；保存关键词、起点、目标和路线模式，切页、托盘及重启后保持工作状态。位置、节点状态或连接变化后自动重算。
- 支持路线线宽与颜色、10%–100% 透明度和可选后台显示；补齐人物引导线、连续有效帧校准及异常长连线防护。
- 地图使用独立只读子进程，切换页面和收进托盘后继续运行，不阻止每小时补丁检测。游戏运行时不写入补丁，无游戏时按已保存配置更新。
- 首次默认关闭读取。在应用内弹窗勾选确认“读取内存存在封号风险，自行承担风险”后记住授权及开关：上次开启则重启恢复，上次关闭则保持关闭；国服及其他服禁止使用。
- 设置中增加免费开源说明、源码与社区链接，以及 7 天前旧缓存、旧日志清理。保留当前日志、配置和还原备份。
- 保留原有物价、DAT、汉化、还原与自动更新行为，更新 Electron 并修复已发现的依赖安全问题。

地图模块选择性迁移自 https://github.com/weixiao030/poe_Plugin ，保留上游 MIT 声明。项目整体使用许可及原有非商业条款不变。

Windows 10/11 x64。Setup 为安装版，Portable 为免安装版，均包含运行环境。每小时自动更新需先成功手动更新一次；应用彻底退出后暂停，下次启动恢复。地图本机验证范围为官方国际服，未承诺 Steam/Epic 或未来客户端版本已实测。发行包未配置项目代码签名。
