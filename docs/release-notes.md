# POE 物价补丁 v1.0.3

修复玩家安装 SHSS 双切繁转简（查价）等汉化补丁后，碑牌词缀价格无法显示的问题。原先部分带颜色的词缀无法匹配，日志出现 `game descriptions do not cover all selected prices`，导致碑牌词缀层整体跳过。

- 识别汉化补丁添加的颜色样式，保留原有双切译文、颜色和词缀数值档位。
- 保持词缀身份、数值范围及固定数字的严格校验，支持减益词缀和重复更新。
- 当前资源已无物价标记时重新建立还原底板，避免还原操作使用汉化前的旧备份而丢失装饰名称。
- 兼容原版游戏资源，通货、传奇与岛屿传言继续按所选范围更新。

**使用顺序：先安装所需汉化／字体补丁，再关闭游戏并更新一次物价补丁。** 如果之后重打汉化补丁，请再更新物价。

1.0.0 及以上版本可在“检查更新”中直接升级；也可下载 `POE-Price-Patch-1.0.3-x64-Setup.exe` 安装。0.x 用户运行本次 Setup。
