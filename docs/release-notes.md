# POE 物价补丁 v1.0.4

- 兼容国服 V7.9 功能补丁的纯中文碑牌描述，支持原版字体、方正准圆字体的 v2/v3 四种组合。
- 根据当前游戏词缀身份与数值范围追加报价，保留原有译文、改色和数值变换；继续兼容原版与 SHSS 双切。
- 优先在线最新碑牌数据；同赛季魔法、稀有报价及汇率过期仍可使用，在线不可用再回退本地缓存，日志保留采样时间。
- 碑牌层未生效时明确显示“部分完成”，执行动态与运行记录保留提示，避免把其他价格更新成功误认为碑牌也成功。
- 先安装所需功能或字体补丁，再关闭游戏更新一次物价；之后重打其他补丁，需要再更新物价。

国服 V7.9 将碑牌描述改为无语言分段的纯中文格式，旧版会跳过碑牌价格层。本版按当前游戏表定位词缀，不依赖固定行号或英文译文匹配。国服原版的普通与 Alt 高级提示已获实机截图确认；原先未提供软件版本的缺价反馈仍无法追溯具体原因。

1.0.0 及以上版本可在“检查更新”中直接升级；也可下载 `POE-Price-Patch-1.0.4-x64-Setup.exe` 安装。0.x 用户运行本次 Setup。
