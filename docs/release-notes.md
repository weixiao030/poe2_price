POE 物价补丁 v0.9.3

- 修复碑牌词缀漏价：结合当前游戏 Mods、Stats、Tags 和底材生成池绑定行情，覆盖名称为空但使用内部 ID 的词缀。
- 恢复总督“额外 1 个阿兹莫里魂灵”的网站参考报价。已知宽查询保留报价并在报告中说明范围；有精确单侧报价时优先采用该侧，未知或不匹配的条件继续跳过。
- 魔法行情过期时继续使用同赛季旧快照，记录采样时间和过期状态；接口失败或校验不通过时使用可用的单侧报价，避免整层碑牌价格消失。
- 碑牌快照暂不可用、分页数据或汇率版本变化时，从第一页最多重试 2 次，日志显示重试原因和次数；不会拼接不同快照。
- 缺少中位价时使用可校验的最低价；在线失败时回退同赛季上次成功快照。单条行情缺失时使用该条可用的一侧，不再跳过整层。各类回退都记录来源和时间。
- 修复日志跟随输出：默认显示最新日志，切换页面返回、重新勾选和窗口尺寸变化时自动滚动到底部。
- 软件更新优先使用 GitHub 国内主源和备用源，8 个国内源全部失败后回退 ZOS；与 POE1 汉化脚本共用源顺序。
- 下载超时、中断、大小或 SHA-256 不符时切换下一源；取消立即停止。签名清单仍须通过内置 Ed25519 公钥验证。
- 提供正式 v0.9.2 → v0.9.3 专用增量 ZIP。GitHub 提供 Setup、免安装 ZIP、增量 ZIP、签名清单及校验文件；ZOS 仅上传增量 ZIP 与签名清单。

价格优先使用挂牌样本中位数，缺失时回退有效最低价。魔法、稀有报价接近时合并，其余显示由低到高的区间，E/C/D 随行情换算。总督魂灵的参考价不代表已逐件核实全部样本属于同一词缀。

支持 Windows 10/11 x64。免安装 ZIP 须完整解压后运行物价补丁.exe；Setup 用于首次安装或手动升级。在线增量包面向原样正式 v0.9.2，其他版本或发行文件被改动的目录使用完整安装版或免安装版升级。

升级软件后，关闭游戏并执行一次物价更新以刷新价签。严格还原恢复官方资源原文；官方繁中裂痕描述原有的多余右括号也会恢复。逻辑还原不压缩 GGPK 中不再引用的历史存储空间。

上传凭据和签名私钥不随源码或发行包提供。发布步骤见[软件增量更新与 ZOS 发布](软件增量更新与ZOS发布.md)。
