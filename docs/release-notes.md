# POE 物价补丁 v1.0.0

统一为 Windows x64 安装版，内置运行环境。保留 POE1 / POE2 的物价、汉化、还原、赛季选择、每小时更新、托盘、自启和现有设置。

软件更新改用成熟的 NSIS / electron-updater。1.0.0 起可以跳过中间版本直接升级：缓存可用时差分下载，差分不可用时下载完整安装包，不再依赖各旧版本的专用增量包。更新优先通过 GitHub 国内镜像，全部失败后使用 ZOS。

更新清单使用 Ed25519 分离签名，安装包校验 SHA-512。保留更新说明、进度、取消下载和重启安装入口；物价、汉化、还原与查询任务未结束时不会安装软件更新。普通退出不会自动安装已下载的更新。

普通用户只下载 Setup.exe。0.x 用户运行一次本次 Setup 完成迁移，现有用户设置和游戏还原备份继续保留。软件升级本身不写入游戏文件。

安装包暂未配置 Windows Authenticode 代码签名。安装中断时可重新运行完整 Setup 修复；不宣称 NSIS 提供业务启动失败后的自动回滚。
