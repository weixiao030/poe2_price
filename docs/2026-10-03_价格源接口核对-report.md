# 价格源接口核对与 v1.0.17 修复

2026-10-03（香港时间）检查了项目使用的 POE1/POE2 普通价格源、两服碑牌词缀、国际服碑牌底材与传奇、国服整件碑牌，以及对应网页、接口文档和公开 JSON。

截图中的 Scout 超时和 Ninja 分类连续失败未在本机复现；独立 GitHub 检查也没有请求失败。另确认国服整件碑牌的交易条件已变化，旧版本会丢弃 4 件有报价的传奇碑牌。本次 v1.0.17 修复这项兼容问题，不能据此承诺解决用户网络超时。

## 已修复的交易条件变化

国服接口现明确规定以下物品至少剩余 1 次使用：

| 物品身份 | 底材 | 稀有度 |
| --- | --- | --- |
| Unforeseen Consequences / 无常因果 | Abyss_Tablet | unique |
| The Grand Project / 宏伟计划 | Irradiated_Tablet | unique |
| Visions of Paradise / 乐园幻象 | Irradiated_Tablet | unique |
| Mastered Domain / 疆域主宰 | Irradiated_Tablet | unique |
| 普通霸主石板 | Overseer_Tablet | normal |

`poe2_whole_tablets.validate_query` 现按物品 ID、底材和稀有度三项共同识别例外。其他普通/魔法/稀有仍要求 10 次，其他传奇仍要求 5 次；服务器、赛季、即时购买、物品名称、底材、词缀筛选和原币种样本校验继续执行。未挂牌不生成价格。

同一份实时响应离线回放：修复前接受 28 条、5 件传奇；修复后接受 32 条、9 件传奇。唯一跳过项为 `Overseer_Tablet:normal` 的 `no_listings`。

## 可转发给用户的排查步骤

截图表示电脑请求海外行情超时，备用行情也没有成功。请先升级最新版、关闭游戏，再按以下顺序尝试：

1. 完全退出物价补丁，包括托盘图标；临时切换手机热点，重新打开并更新物价。热点成功而原网络失败时，重点排查原网络或代理规则。
2. 没有使用代理时，检查 Windows“设置 → 网络和 Internet → 代理”是否残留失效的手动代理；仅关闭确认已不用的代理。正在使用代理时，确保代理服务正常，并让物价补丁的 `poe_python.exe` 请求也经过有效链路。只加速游戏或只安装浏览器代理插件，不保证行情请求能走代理。修改后完全重启补丁。
3. 同机打开 [Scout 快照](https://api.poe2scout.com/poe2/Leagues/forbiddenrites/ExchangeSnapshot) 和 [Ninja 通货接口](https://poe.ninja/poe2/api/economy/exchange/current/overview?league=Forbidden%20Rites&type=Currency)。正常应显示 JSON；超时说明该链路仍未恢复。浏览器成功也不能证明后台 Python 使用相同代理。
4. 如仍失败，从“运行记录”导出完整日志，连同软件版本、国服/国际服、所选赛季、热点对照结果一起反馈。日志需要从开始抓取到最终错误，不能仅截取中间的“分类失败”。403/429、DNS、TLS 和超时的后续处理不同。

重装游戏或删除还原备份不能修复这类网络请求失败。v1.0.17 的碑牌兼容修复需在升级后再成功更新一次物价才会应用到游戏。
