**v0.8.5 的碑牌功能没有完成可用集成。截图里的怪物稀有度 `=2D` 是 9 月 20 日手工测试资源中的固定文字，并非这次 API 报价。** 本机 17:02 更新因缺少碑牌模板跳过了碑牌层，最终 ZIP 只有三个 DAT。只补模板提取仍不能完成安装：生成器会破坏 CSD，兼容检查会拒绝引用变化，正式安装器也不能新增虚拟资源。现有五个碑牌测试全部通过，恰好表明测试没有覆盖这些故障，不能支撑此前“完成并发布”的判断。

本轮完成重新分析和隔离复现，新增本报告与复现材料；没有修改生产源码、游戏文件或发布新版本。原功能修复仍未完成。

## 其它必须纳入修复的边界

- `Assert-GgpkPatchApplied` 只读回三类 DAT，无法证明新增 `.it/.csd` 已索引、可读取、内容正确。Bundles2 的读回目标也没有覆盖碑牌资源。
- `New-CorePricePatchFromCache` 只重新打包 BaseItemTypes。如果未来允许碑牌引用通过兼容检查，该缓存必须同时保留其依赖资源，或者将引用安全还原；不能只丢掉 `.it/.csd`。
- 禁用碑牌和逻辑还原没有专门清理 `Poe2Price` / 已知旧测试引用的处理。不能通过旧的整份索引恢复解决，会覆盖测试之后其他补丁的索引变化。
- 生成器目前按整个 description 块选最大报价并写入中文分支，没有严谨的数值分支对应。`changed` 会在正则实际未替换时增加；真实祭祀数据报告 98 次改变，实际只生成 94 个价签，而且这 94 处都有 U+0001。部分不以 `#|-1` 标示的负向文案也需要检查。
- `_tablet_text_key` 把固定数字和范围归成同一键；真实 Overseer 数据有四组 `1` 与 `(1-2)` 合并。不能仅凭最大值合并认定价格适用于所有数值。
- 数据请求尚未验证返回的赛季、`status`、分页快照 ID、报价完整性；缺汇率时还有 477 的固定兜底。遇到这些情况应跳过受影响报价并保留其它正常功能。
- 参考测试同时重定向英文和繁体两张表；正式实现只有目标语言表。需要对照游戏真实资源选择行为验证两张表及不同语言，不能把单表写入等同于参考实验已复现。

上述项目为源码复核发现的修复边界；本轮没有逐项执行禁用、缓存、还原等实机流程，不将它们描述为已发生的用户故障。

## Path 与修复要求

P-01（path_type=`callflow`）：从用户点击通货更新，到截图仍显示旧价签。

1. GGPK 分支只提取既有 DAT，未取得碑牌模板。evidence=E-01/E-03，finding=F-01。
2. Python 因缺前置文件跳过碑牌层，生成 ZIP 只含三个 DAT。evidence=E-01/E-02，finding=F-01。
3. 更新保留原基础表的 PriceTest 引用，旧测试 CSD 的固定 2D 仍有效。evidence=E-02，finding=F-01。
4. 安装、读回三份 DAT 成功后输出操作完成；此成功仅覆盖实际三个条目。evidence=E-01/E-03，finding=F-01。

P-02（path_type=`callflow`）：从成功获得模板，到正式功能仍受阻。

1. API 报价经过文本归一化，部分词条漏匹配。evidence=E-03/E-04/E-07，finding=F-05。
2. CSD 输出被错误替换串破坏。evidence=E-03/E-04，finding=F-02。
3. 重定向后的 DAT 被外层兼容检查拒绝，影响整个新补丁构建。evidence=E-03/E-04，finding=F-03。
4. 即便绕过该阻断，旧安装器也拒绝新的虚拟路径。evidence=E-05/E-06，finding=F-04。

修复应保持原需求：碑牌属于“通货与更新”，无额外模块；报价失败重试耗尽后仅跳过碑牌层。具体需要连通以下范围：

1. 两种安装模式统一提取原始模板，验证 BOM、格式及当前游戏版本，并将可选模板失败限制在碑牌层。
2. 建立底材、stat ID、数值分支到报价的明确对应；保留链接文字、语言段、引号和换行，正确处理末尾 `negate` 等指令。校验真实改动数、匹配覆盖与控制字符；无有效匹配不能报告成功。
3. 沿用参考实验的独立模板方案，补齐新增 bundle、文件记录与目录路径的索引能力。先在副本验证所有无关映射不变，再安装并读回所有资源及其引用。
4. 兼容检查只允许已知碑牌行、已验证目标路径的引用变化，继续拒绝其它结构变化。统一处理缓存依赖、关闭碑牌、旧测试引用迁移和逻辑还原。
5. 分清 API 单位和 Ninja 变体口径。不能把 Normal/Magic/Rare 的不同市场价合并为一个无条件底材价，也不能在没有实时汇率时使用固定 477。
6. 验证首次安装、重复更新、API 失败跳过、关闭、还原、缓存降级及 GGPK/Bundles2 两条链路；覆盖截图三类实际词条。通过这些检查后才具备再次发布的证据。
