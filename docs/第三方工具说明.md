# 第三方工具说明

本源码包包含用于 POE2 资源读写的第三方工具。

- `物价补丁/tools/GGPKExtractor`
  - 从国际服官方独立端 `Content.ggpk` 提取物品表。
- `物价补丁/tools/BundleExtractor`
  - 从 `Bundles2\_.index.bin` 指向的 bundle 中提取指定虚拟文件。
- `物价补丁/一键安装特殊补丁工具/PatchBundledGGPK3.*`
  - 把补丁 zip 写入 `Content.ggpk`。
- `物价补丁/一键安装特殊补丁工具/PatchBundle3.*`
  - 把补丁 zip 写入 Bundles2。
- `物价补丁/tools/localize_poe1.ps1`
  - 每次查询 PoEDB 推荐的 LibGGPK3 最新正式 Release，并按 `ghfast.top`、`gh-proxy.com`、`gh.ddlc.top`、`ghproxy.it`、`github.boki.moe`、`ghproxy.net`、`gh.jasonzeng.dev`、`gh.monlor.com`、GitHub 官方源依次获取 `PoeChinese3_win-x64.exe`。文件大小和 SHA256（或 Release 页面公布的 SHA256）必须匹配，且 PE/产品身份校验通过后，才会对 POE1 国际服 `Content.ggpk` 或 `Bundles2\_.index.bin` 执行繁体中文化；完成后进入游戏选择第二个（法文）国旗。`bdnb.cn` 与无具体仓库地址的 Gitee 不在自动下载链路中。

本项目会写入当前客户端对应的 `BaseItemTypes.datc64` 和 `Words.datc64` 虚拟资源。修改游戏文件存在封号或校验风险，请关闭游戏后使用并自行承担风险。
