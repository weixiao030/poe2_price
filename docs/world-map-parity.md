# 世界地图功能迁移对照

对照上游 `weixiao030/poe_Plugin` 的 `7dde80bf90d38eae5773c82de4797999c1008cf1`，范围为 WPF Atlas 世界地图、搜索、路线与专属覆盖层。0.8.0 的逐项复核发现缺口后已取消发布；0.8.1 补齐下表。

| 上游功能 | 0.8.1 实现 | 验证入口 |
| --- | --- | --- |
| 节点、名称、状态、隐藏节点、连接、当前位置及内容标签 | 独立只读 `world-map/` 服务，保留上游解析与翻译数据 | `probe-world-map.mjs`、`SelfTests.cs` |
| 编号、网格、简繁/英文名称与内容搜索 | 原搜索算法；工作台显示所有匹配项，每页 60 条 | `SelfTests.cs`、`verify-world-map-ui.mjs` |
| 距离、相对 X/Y、近到远排序 | `rankAtlasNodes`，距离相同按编号排序；无基准明确显示未确认 | `world-map.test.ts`、150 条搜索结果 UI 用例 |
| 当前起点、手动起点、最优可开启起点 | 原路线算法；普通路线拒绝不存在起点的假直达回退 | C# 27 项自测、实机路径输出 |
| 游戏覆盖层点选起点 | 临时接收鼠标；完成、右键、20 秒上限、失效帧或停用时恢复穿透 | `world-map-overlay.test.ts`、`verify-world-map-overlay.mjs` 的原生窗口样式与点击验证 |
| 路线工作状态保存 | 主进程持久化搜索词、所选节点、手动起点、规划目标和模式；切页/重启恢复 | `verify-world-map-ui.mjs` 的实际配置文件及重启验证 |
| 地图更新后自动重新规划 | 每次后台采样按同帧拓扑、节点状态及起点缓存或重算；旧代际/旧参数结果不覆盖新状态 | `AtlasSession` 自测、实机切页持续采样 |

| 重新校准 | 立即隐藏旧图并清本地缓存；至少两个不同时间的连续有效帧后恢复 | `AtlasSession` 自测、实机 reset 验证 |

所有运行证据来自本机 `verification/VERIFICATION.txt` 及 `desktop/test-results/`。发行包另执行 `verify-package.mjs`、`verify-world-map-ui.mjs --packaged` 和已授权的 `verify-world-map-overlay.mjs D:\poe2 --packaged`。离线图形夹具验证与真实游戏采样分开记录；地图类型的精确标签未在某帧观察到时不声称已识别。

## 与上游不同但保留用户要求的行为

- 首次默认关闭，需要应用内风险确认；授权后记住最后开关。上游默认开关不直接照搬。
- 限定 POE2 国际服及所选进程目录，其他服拒绝启动；独立模块与物价补丁每小时任务并行。
- 覆盖层为 Electron 透明窗口，平时不抢焦点、鼠标穿透；标签避让及 HUD 裁剪沿用本应用设计。
- 原引擎、缓存清理白名单与还原文件保护不因地图迁移而变化。

## 未混入或未当成可用功能迁移的内容

自动喝药、无限进门、区域雷达、怪物/掉落、网页雷达、OBS 等属于其他模块。上游控制台的 `ShowPath`/`UseCuratedLandmarks` 消费者是雷达引擎，不是 Atlas 覆盖层；`DrawAllLandmarkPaths` 只找到设置写入。F11 控制整个雷达总开关，F10 实际打开导航控制台，不是 Atlas 专属快捷键。

`Import_Click` 只调用 `RefreshSourceAsync` 定位并保存数据源；没有调用 `MapImporter`。`MapImporter` 与 `AtlasCoordinateCalibration` 在当前生产代码未找到外部调用，不将未接入类包装成已可用功能。世界地图运行仍依赖实际客户端内存，元数据由随包目录提供。

兼容性实测范围为本机官方国际服及窗口化环境，不代表未来客户端、Steam/Epic、独占全屏或其他用户机器均已通过测试。
