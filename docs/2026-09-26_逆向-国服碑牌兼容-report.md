# 国服碑牌价格与 V7.9 兼容分析

分析日期：2026-09-26。使用 Python、LibBundle3 资源解析、项目安装器及 Electron 测试脚本。范围与授权见 [scope.md](cn-tablet-v104/scope.md)。本文为普通资源格式分析，不涉及安全漏洞。

## 结论

国服原版碑牌的物品继承字段没有写错位置。用户提供的普通提示截图、Alt 高级提示截图，以及同一物品按 Alt 后仍保留价格的确认，证明原版分类描述链路可用。原始缺价玩家的软件版本不明，不能据此追溯其故障原因。

用户提供的国服 `[Poe2][0.0.0.62]_V7.9_正式版` 确实存在另一种兼容问题：四种组合的碑牌 CSD 都把默认段替换为中文，并移除 `lang` 分段。v1.0.3 依赖英文记录匹配并向中文分段写价，因而无法覆盖这些描述，整层安全跳过；其他物价仍可成功，旧桌面却显示全部完成。

v1.0.4 识别纯中文默认段，通过本地 Mods/Stats/Tags 与碑牌类型绑定词缀身份，使用 Mods 的原始数值范围插入报价。它不依赖中文翻译内容匹配，不把句中的固定数字当作属性范围，保留原文、颜色、分支顺序和数值变换。仅单属性、已绑定身份、已知变换参与标价，未知情况仍不猜测。

## 使用方法与边界

先安装所需功能/字体补丁，再关闭游戏，在物价工具中执行更新。以后重打第三方补丁会替换索引，需再次更新物价。未安装字体/功能补丁的原版仍走原有语言分段路径。

市场报价缺失不等于资源不兼容：按用户要求，优先请求在线最新数据，同赛季快照和汇率即使过期也继续使用并记录时间；在线失败才回退同赛季缓存。仅在在线与缓存均无有效报价时不生成碑牌价格，新版会明确提示。软件升级本身不写游戏文件。游戏更新造成的结构或内容变化仍需重新验证。
