# v0.8.3 赛季优化发布审计

本次审计覆盖最新赛季自动发现、手动固定选择、国服当前 / 历史接口、来源标识、缓存和桌面参数传递。发现并修复了目录缺少当前赛季时未查备用源、损坏缓存部分条目被复用、缓存发布失败误报成功三个边界问题。修复后未发现本次差分中仍需阻止发布的问题。结论限于下述范围及验证结果，不表示对整个历史代码库作出无漏洞保证。

## 范围与信任边界

授权和基线见 [scope.md](audits/v0.8.3/scope.md)。外部数据入口为 Scout、Ninja、poecurrency 的赛季响应，本地入口为保存的设置与缓存；受保护对象为所选赛季身份、补丁缓存和游戏文件。审查确认：赛季参数经过 IPC 类型 / 长度校验，国服历史参数使用 URI 编码，PowerShell 通过 JSON 文件和参数表接收数据，Python 子进程使用参数数组；没有把外部赛季字符串拼成执行脚本。

## 发现与处置

| Finding | 级别 / 状态 | 位置与影响 | 处置与证据 |
| --- | --- | --- | --- |
| F-001 | 中 / 已修复 | `poe_patch_leagues.ps1:Get-PoePatchOnlineLeagueOptions` 在主源只返回历史赛季时直接结束；Python 目录还可能把第一条历史记录标为最新 | 无当前项时继续尝试独立目录；仅历史项仍可手动选择；“最新”必须对应当前项。E-001 |
| F-002 | 中 / 已修复 | `poe_patch_leagues.ps1:Get-PoePatchLeagueOptions` 过滤损坏记录后仍复用剩余缓存，国服自动模式可能给当前价格附上历史赛季身份 | 任一记录损坏则拒绝整份缓存；国服自动模式另外检查当前标记，身份未知时禁用赛季补丁缓存和国际参考。E-001 |
| F-003 | 中 / 已修复 | `update_price_patch.ps1` 的兼容缓存复制失败分支使用 `return`，可能使 worker 误报成功 | 改为异常出口，已有游戏文件保持原状，由既有自动更新失败调度处理。E-004、E-003 |
| F-004 | 信息 / 人工复核完成 | Bandit 的 B404 两项、B603 两项、B112 一项，均为既有代码位置 | 子进程仅以参数数组执行本地补丁构建器，未启用 shell；翻译请求异常仅跳过可选翻译候选。未发现这些提示对应本次新增可利用路径。E-002 |

以上修复结论置信度为高；F-003 的磁盘故障分支以代码控制流检查确认，本次没有对真实游戏或磁盘注入故障。

## 调用路径

P-001（callflow）：界面选择自动 / 固定模式并保存普通 JSON 对象（E-003）→ 主进程校验请求 → worker 解析对应游戏与服区目录（E-001）→ 当前目录缺项时查备用源，损坏缓存被拒绝（F-001、F-002）→ 构建器仅使用已解析来源 ID → 构建及兼容缓存均失败时经异常出口报告失败（F-003、E-004）。

外部价格源的停机和数据延迟仍可能造成更新失败；此时保留已有补丁。旧自动更新配置继续按固定赛季恢复，需要用户选择自动模式并成功手动更新一次后才跟随最新。真实游戏安装不在本次验证范围。
