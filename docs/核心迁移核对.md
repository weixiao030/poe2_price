# 原项目核心迁移核对

对照仓库 https://github.com/weixiao030/poe2_price 的 main 提交 `23e6dd40c7786fdb06491ce5dabb5aceb2c7381f`（历史基线 v0.6.8）。当前桌面应用和发行包统一为 v0.8.1；原物价引擎保持字节一致，其 HTTP User-Agent 是历史引擎标识，不是应用版本。

32 个核心源码、数据契约和工具文件与该提交一致：文本仅归一化 UTF-8 BOM / 换行比较，二进制按字节比较。另外核对了 16 个安装工具、提取器源码和还原种子相关文件。清单在 [core-provenance.json](core-provenance.json)。`npm --prefix desktop run test:migration` 同时检查源码与实际打包引擎一致、两个还原种子存在、旧入口不再打包。

| 原功能 / 代码 | 当前实现与验证 |
| --- | --- |
| build_poe1_price_patch.py、build_poe2scout_price_patch.py、price_sources | 原算法直接复用；同名匹配、价格单位、多个来源补缺、国服质量门槛、分页与超时回归保留 |
| poe2_name_price_patch.py、poe2_island_rumour_patch.py | 原 DAT 写入与名称清理直接复用；通货 / 传奇 / 岛屿范围切换回归保留 |
| update_price_patch.ps1、update_poe1_price_patch.ps1 | Electron worker 调用；不重写缓存、赛季隔离、低匹配保护、事务写入与重试 |
| restore_price_patch.ps1、restore_poe1_price_patch.ps1、poe1_patch_common.ps1 | 原逻辑 / 物理恢复、兼容签名、基线迁移、读回校验保留 |
| poe_patch_profiles.ps1、poe2_patch_common.ps1 | 原目录发现、手动选择、服区 / 语言 / 赛季解析和目录互斥保留 |
| localize_poe1.ps1 | 原下载来源、SHA256 验证及 PoeChinese3 汉化流程；新增缺简体时自动接入 |
| GGPK / Bundle 工具 | 保留原二进制与提取器源码，逐文件比较与打包哈希检查 |
| 还原种子 | 补齐桌面包缺失的两个种子；原兼容验证和客户端专属基线仍为准 |
| 旧 GUI 的参数传递 | typed IPC + policy.ts；POE1 不接收 POE2 专用开关，历史赛季 false 保留；对应参数测试 |
| 旧自动更新 worker | main 调度 + worker；成功配置复用，游戏运行 / 同目录互斥时跳过；还原成功保留开关，只有手动关闭才清空调度 |
| 旧 C# 启动器与 WinForms UI | Electron 唯一入口；目录、范围、语言、还原、汉化、托盘、历史与日志通过桌面交互验证 |

删除的是旧界面专属构造测试、旧 payload / 启动器二进制复制测试；混合测试中的核心断言保留。旧 GUI 的互斥、参数、取消与状态行为由桌面契约和 Electron 流程验证，发布一致性由当前 manifest / provenance 检查替代。

实机证据覆盖两份国际服 GGPK 的全量、仅通货、仅传奇、POE2 岛屿开关 / 仅岛屿、POE1 汉化及语言模式、重复更新、还原及每次独立提取的 DAT 哈希。已按用户要求停止启动游戏客户端；运行中游戏保护不宣称完成新的游戏进程实测。国服 / Steam / Epic 未在本机安装，依靠保留的原核心回归验证，不把源码一致性说成这些客户端已实测。
