# v1.0.6 两服 E/C/D 价格显示

POE2 国服、国际服的通货、传奇/暗金、碑牌底材及词缀共用显示规则。所有价格仍沿用原有取样与过滤：神圣石、崇高石不追加参考价，原先被低价门槛过滤的条目继续隐藏。POE1 的定价逻辑保持原有行为。

## 单位和小数

同一次更新采用本服已校验行情中的 E/C/D 比率。小额使用 E，达到 1C 转为 C，达到 1D 转为 D；C 不在 E、D 币值之间时跳过 C，缺失汇率时跳过对应单位。最终数字直接截断至两位小数并去掉末尾零，不四舍五入。极小正数保留到首个非零位，底层不使用截断结果参与后续计算。

词缀继续根据既有市场分布规则决定合并或区间。合并后按实际单价选单位；区间按低价端选单位，两端统一，分别截断。例：1C=87E、1D=535E 时，110E 显示 1.26C，600E 显示 1.12D，80~170E 保留 E，110~270E 显示 1.26~3.1C。

国际服各来源先保留其报价价值，再采用本次国际服显示汇率；国服不借用国际服汇率转换本地行情。显式标记的国际参考补缺仍使用国际市场自己的换算口径。碑牌历史快照先按自身汇率还原价值，再按本次显示汇率输出。在线优先、同服同赛季旧行情/汇率的回退继续有效。

全量行情分析发现，国际服合并 Scout 与 Ninja 价格时曾丢失报价自身的神圣汇率，导致部分暗金发生二次换算。现在合并时保留每条报价的来源汇率，普通价格、备用价格和碑牌一致使用原始价值。构建会输出 `price_display.audit.json`，保留全部有效报价、隐藏原因、来源汇率和最终价签，便于逐项复核；国际服碑牌报告同时保留未截断的 Divine 原价。

## 碑牌名称与兼容

国服名称沿用国际服及暗金的共享格式，例如 `[1.26C|裂隙石板]`，不再并列普/魔/稀三个报价。普通报价优先；缺普通时沿用可用报价选取逻辑，所选稀有度、原始金额/币种和完整分档报价写入报告。该名称是底材参考，不按当前物品实例稀有度切换。

更新会清理 v1.0.5 的旧名称价签，保留本地字体补丁译文和描述继承；英文底材保留原名以兼容过滤器。整件和词缀来源继续独立，暗金无价行为与更新范围保持原有规则。

验证记录保存在本地 `verification/price-display-v106/`。写入与读回验证不等同于游戏内悬浮画面验收。
