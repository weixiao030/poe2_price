验证日期：2026-11-14。检查实际游戏资源、公开赛季目录、行情页面与 JSON、更新签名、完整下载包及运行环境。

## 实现

- Scout 目录的 ShortName 用于保存选择，接口按精确匹配的 Value 构造路径，例如 `Forbidden%20Rites`；目录不存在该赛季时拒绝猜测和跨季取价。行情客户端启用 gzip，压缩前后均有限制，校验 gzip 完整性，并使用明确的应用 User-Agent。
- POE1 Ninja 审计补齐 30 个实际抓取分类及传奇，读取网页 Astro 分类模块，对照 46 个网站分类。按地图、词缀等变体报价的 16 个页面明确列为不可写入通用名称的变体视图。POE2 网站的 23 个分类与现有适配一致。
- 更新国服新增历史报价及质量字段的契约基线，现有 OCR 校验已读取这些字段。PoEDB 审计接受真实 HTML 类型并同步页面目录。Scout 通货分类通过实际快照价格确认覆盖，空分类仍报警。
- 增加两服碑牌只读巡检，并纳入定时任务；检查赛季、汇率、两种稀有度和整件报价。严格新鲜度巡检会报告过期，生产流程仍按既有规则使用同赛季旧快照并提示时间。
- 移除完整汉化下载持续超时的 ghproxy.net；保留四个通过完整载荷校验的镜像及各自备用链。替换旧 .NET Azure Edge 下载地址为官方 Blob，保留官方 builds 备用。
- 内置运行环境升级为 Python 3.13.17、.NET 8.0.34，更新 SHA256/SHA512。Python 3.13.18 尚无 Windows embeddable 包，未使用不存在的载荷。
