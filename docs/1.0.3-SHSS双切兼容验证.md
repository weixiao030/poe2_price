# v1.0.3 SHSS 双切补丁兼容验证

验证日期：2026-09-25。目标为用户提供的 POE2 国际服官版 0.5.5c(4.5.5.3) SHSS 双切繁转简（查价）v2.0 补丁。

## 故障与修复

双切补丁用 `<AT1>{{…}}`、`<DF1>{{…}}` 等显示样式给词缀着色，并将部分词缀拆成多个数值档位。旧版把显示样式当成英文正文参与匹配，导致 254 条有效报价中有 23 条无法匹配，随后跳过整个碑牌词缀层。用户日志里的三个裂痕碑牌 ID 均在复现结果中。

`poe2_tablet_prices.py` 新增成对样式解析，只在文本和数字匹配时忽略样式。实际输出保留原文、颜色、链接、数值条件、负数变换与未报价回退。Stat 身份与固定数字校验继续执行，无法解析的样式不被猜测匹配。

实际还原测试还发现：装汉化前遗留的物价还原包可能与新汉化 DAT 结构一致，但名称不同。`update_price_patch.ps1` 现在在当前 BaseItemTypes、Words、EndgameMaps 均无自家标记时优先用当前资源建立底板；重复更新发现已有自家标记时仍复用原备份，避免备份污染。

## 验证范围

在本机 `D:\poe2\Content.ggpk` 备份原物理索引及同名 bundle 后，安装完整 SHSS 补丁的 `_.index.bin` 和 `Tiny.V0.1.bundle.bin`，逐字节读回。然后通过最终 v1.0.3 打包桌面程序执行全量更新（含岛屿传言）、重复全量更新、还原。

本次实机测试指真实客户端文件的写入、读取和桌面操作流程，没有启动游戏进入场景做字体渲染或物品悬浮窗画面验收。字体文件本身未修改。

| 检查 | 结果 |
| --- | --- |
| 原版和 SHSS 的同批行情匹配 | 两者均为 254 / 254；修复前 SHSS 为 231 / 254 |
| 最终桌面程序在线构建 | 8 类碑牌、254 条词缀报价，625 条普通价格、367 条传奇价格 |
| 数值分支 | 简繁中文共 6,482 个整数数值检查，均在首个命中分支显示对应价签 |
| 价格数据 | 魔法、稀有独立取价；3 条单侧报价和 1 条网站宽查询参考均按原规则记录 |
| 更新与重复更新 | 真实 GGPK 写入成功并读回校验；碑牌名称保留汉化格式 |
| 还原 | 三份共享词缀模板与包含 5,072 个名称的物品表均与 SHSS 原文件逐字节一致 |
| 自动回归 | Python 398 项、桌面契约 45 项通过；核心来源与打包一致性通过 |
| 安装与更新 | NSIS 356 个载荷文件核对通过，中文路径启动通过；独立应用 ID 的真实跨版本 NSIS 更新通过 |
| 客户端契约 | POE1/POE2 的官方、Steam 和 WeGame 夹具检查通过 |
| 发布检查 | 最终源码、未压缩程序和 Setup 隐私检查通过 |

测试结束恢复原物理索引、同名 bundle 和测试前的物价还原材料，读回核对。测试生成但未引用的 bundle 保留；不声称 GGPK 文件大小或物理布局完全回到测试前。

## 本地证据

- `verification/shss-compat/`：补丁提取、问题复现、全数值分支验证、构建和自动回归日志、原始物理备份。
- `verification/desktop-v1.0.3/real-jobs/`：桌面操作请求、结果、独立读回、实际生成的补丁与行情报告。

用户操作顺序为：安装所需汉化／字体补丁 → 关闭游戏 → 更新物价。如果随后重新安装汉化补丁，再更新一次物价即可。
