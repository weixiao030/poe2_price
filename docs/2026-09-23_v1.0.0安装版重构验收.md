## 真实游戏操作

使用最终打包 EXE、生产 IPC 和内置引擎，对本机已存在的 `D:\poe1`、`D:\poe2` 执行 10 次真实操作，全部返回成功并从 GGPK 读回验证；没有启动游戏进程：

- POE1：汉化、全部物价、还原、再次全部物价。
- POE2：全部物价与岛屿传言、仅通货、仅传奇、关闭价格保留岛屿传言、还原、再次全部物价与岛屿传言。

最后两个客户端均重新应用完整物价补丁。Steam / WeGame 安装结构通过客户端夹具验证；当前机器的真实写入覆盖官方 GGPK，不能等同于在每一种发行平台上实际运行了游戏。

四组实际赛季目录均返回非回退数据。8 个价格来源均取得可用数据；国服 POE2 / POE1 当前接口分别返回 559 / 458 项。部分第三方分类返回不完整数据，既有补缺与跳过逻辑正常生效；碑牌旧快照与单侧报价按现有界面和日志提示，不将这些情况记为全部行情齐全。
