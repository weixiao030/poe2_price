# v0.8.6 碑牌修复与真实文件验证

本次修复覆盖碑牌报价生成、资源安装、失败隔离、缓存与还原。2026-09-21 在授权的 `D:\poe2\Content.ggpk` 上实际写入并读回验证，同时在真实 Bundles2 资源副本上验证新增路径。测试结束已重新安装完整价格功能。没有启动游戏进行画面验收；本报告的结论限于资源内容、引用、索引、读回一致性及桌面程序流程。

## 故障、修复与证据

| 证据 | 发现 | 修复路径 |
|---|---|---|
| 正式流程此前没有碑牌模板，清理函数也会删除已提取模板 | 仅添加 Python 生成逻辑不能实际安装 | `update_price_patch.ps1` 两种安装模式均提取并保留四份模板 |

| 原安装工具只能替换已索引条目 | 新 IT/CSD 不会进入实际资源索引 | `ResourcePatch.cs` 暂存独立 bundle、文件记录和目录记录，校验全部原记录，再独占提交和读回 |
| 旧实验模板会继续显示固定 `2D` | 关闭或跳过不能只省略资源文件 | `poe2_tablet_refs.py` 清理已知继承引用，覆盖英文表、目标语言表、缓存和还原 |
| Divine 原始报价换算方向错误，Ninja 稀有度报价被混用 | 价格口径不可靠 | 使用返回的汇率及完整转换结果；保留词缀数值范围；底材按普通、魔法、稀有分别展示 |
