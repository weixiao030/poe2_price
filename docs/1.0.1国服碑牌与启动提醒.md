# 1.0.1 国服碑牌与启动提醒

POE2 国服使用碑牌行情 API 的 `server=cn` 市场。游戏文件实读确认 Mods、Stats、Tags、BaseItemTypes 的记录宽度分别为 693、106、44、360 字节，8 类碑牌可生成 254 组正权重词缀组合。2026-09-24 采样时，国服魔法、稀有实时视图各有 252 行，其中各 251 行报价有效；251 组词缀全部绑定到国服游戏属性，无报价项保留原文。

## 数据边界

- 先读取国服赛季目录，将 poecurrency 的赛季标识映射到国服交易赛季名称。固定历史赛季不能回退当前赛季或国际服赛季。
- 国服使用 `view=live` 中经过服务端校验的有效行。分页间核对完整快照 ID、本轮 ID、修订号、汇率 ID、总条数、服务器、赛季和稀有度；轮次变化从第一页重试。
- 国服汇率以崇高石为基准，先归一为神圣石价值，再按每个稀有度自己的汇率换算。缓存带国服市场身份，不能读取国际服缓存。
- 交易查询只接受相应服务器的交易域名和本赛季，核对魔法/稀有查询条件并以游戏 Mods/Stats/Tags 绑定词缀。国服不调用国际服碑牌底材价格源。
- 普通通货、传奇及岛屿提示沿用原流程。碑牌接口或模板失败时只跳过碑牌层，清理已有碑牌引用，日志记录原因。

## 启动提醒

主进程每次启动执行一次签名更新检查，不等待游戏目录查询；后台托盘启动也执行检查，保持零窗口。普通窗口打开后，右上角提醒显示约 3 秒，鼠标悬停、键盘聚焦或窗口隐藏时暂停计时。

“查看更新”进入现有更新页。只有用户在更新页主动更新才下载并安装。关闭提醒只影响本次进程；“本次更新不再提醒”按发布版本写入用户数据目录的 `software-updates/notice.json`，后续版本仍会提醒。网络失败及已经最新版时不弹提醒。

## 验证命令

在项目根目录执行：

```powershell
python -X utf8 -m pytest tests -q
npm --prefix desktop test
node desktop/scripts/verify-startup-notice.mjs
node desktop/scripts/verify-installer.mjs
npm --prefix desktop run test:software-updates
```

指定客户端的实机验证会真实写文件，请先退出游戏：

```powershell
node desktop/scripts/test-real-games.mjs --game-dir "游戏根目录" poe2-restore poe2-currency poe2-currency poe2-restore
```

本地完整证据在 `verification/desktop-v1.0.1/`，包括原始资源、API 分页、映射报告、界面截图、打包程序的真实任务结果和回读哈希，不随安装包分发。

## 2026-09-24 验收结果

387 项 Python 测试、45 项桌面测试、启动提醒交互、真实 NSIS 跨版本安装与载荷校验均通过。使用最终 1.0.1 打包程序在国服 WeGame Bundles2 客户端依次执行还原、物价更新、再次更新、最终还原，四次操作退出码均为 0。

两次更新均生成 8 类碑牌资源，绑定 251 组国服有效报价，3 组无报价保留原文；每次写入后均回读验证全部 19 项资源。重复更新期间，逻辑还原包和物理还原包中的原始文件哈希保持一致。最终还原后，7 个关键资源与干净基线一致，4 个物理索引文件也与首次备份逐字节一致。测试结束时游戏处于已还原状态。审计结果保存在 `cn-roundtrip-audit.json`。
