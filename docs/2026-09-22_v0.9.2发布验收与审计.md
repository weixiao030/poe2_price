## 源码安全审计

standard profile，15 个覆盖单元，未使用旧审计覆盖替代当前复核。两轮猎取和独立覆盖批评完成；3 个候选经独立验证，保留记录再经独立核验。结构化记录及覆盖账本均通过校验。

结果为 0 个动态确认漏洞、1 个待验证记录、2 个被否定候选；这不是无漏洞保证。审计代理只读源码，没有满足完整 OS 隔离要求的动态漏洞夹具环境；普通功能测试不冒充安全漏洞复现。云 IAM、外部行情服务内部、游戏和第三方运行库内部不在本轮源码证明范围内。

| Evidence | Finding | Path / 处理 |

## 隐私边界

客户端只携带公开下载地址与验签公钥。上传 Endpoint、AK/SK、签名私钥、上传配置和私人工作目录均不提交、不进入发行包。已将隐私扫描接入发行 CI；本机还额外使用私有禁止值检查源码和解包载荷。原始诊断和游戏提取材料保存在忽略目录，不随发行分发。

复现普通回归：`python -m pytest tests -q`、`npm --prefix desktop test`、`npm --prefix desktop run test:migration`。真实双服验证需用户拥有且已关闭的游戏安装，显式传入两个目录运行 `desktop/scripts/verify-real-poe2.mjs`；不会自动猜测目录或启动游戏。
