# v0.9.3 发布验收

本版修复碑牌漏价及单侧行情过期时整层价格被跳过的问题，并将软件更新切换为 GitHub 国内主备用源优先、ZOS 兜底。GitHub 提供 Setup、免安装 ZIP、专用增量 ZIP、签名清单和 SHA-256 清单；ZOS 本次只上传增量 ZIP 与签名清单。

## 碑牌与真实游戏文件

在当前游戏数据中核对 86 个不同 Mod、254 个底材词缀组合。双侧有效快照和当前在线稀有快照均能生成 254 组价格；当前魔法快照过期时只使用有效稀有报价，报告明确记录来源，不将过期数据混入区间。

总督“额外 1 个阿兹莫里魂灵”的网站报价存在，当前在线构建显示 `10C`。该来源交易查询可以匹配另一种魂灵词缀，作为网站参考价保留并在报告的 `query_scope_warning` 中说明；未知查询条件和不包含目标词缀的查询仍拒绝使用。

真实写入、官方启动及启动后回读结果：

- 20 项补丁资源与发行版内置 Python 构建结果逐字节一致。
- 254 组均有价格，12,964 项整数取值、简繁中文、共用稀有度映射检查通过。
- 3,647 行中文 CSD 括号平衡；最终补丁启动前后索引哈希一致，启动日志没有重新下载索引。
- 生产还原脚本执行两次：第一次恢复 4 项 DAT；第二次报告资源已是当前版本，无需写入。
- 还原后 13 项受检资源与官方 4.5.5.3 原始文件逐字节一致，碑牌继承引用恢复。还原后官方启动通过，索引仍一致。

严格还原会恢复官方繁中裂痕文本原有的多余右括号。逻辑还原会保留 GGPK 中不再引用的历史条目和空间，不代表整个 GGPK 字节或体积恢复出厂。这里验证资源写入、游戏启动和读回，未逐个登录角色打开所有物品提示框。

## 发行包与在线升级

原样正式 v0.9.2 的 355 项发行文件逐一通过保存基线的 SHA-256 校验。使用正式签名、正式增量 ZIP，在隔离副本通过本地 HTTPS 完成真实下载、校验、退出旧版、安装、自动重启及 v0.9.3 健康回执；最终 355 项目标文件回读一致，玩家自存文件保留。

增量包只包含 17 项变化文件及安装清单，大小为 110,254,285 字节。版本资源变化使完整 EXE 成为变化文件，因此增量包不是此前约 0.84 MB 的界面测试包。为避开存储中的历史测试对象，正式文件名为 `POE-Price-Patch-0.9.2-to-0.9.3-release-delta.zip`。

Setup 内的 356 项载荷与发行目录逐项一致。免安装 ZIP 在独立中文目录解压，355 项文件哈希一致，实际 EXE 启动、内置引擎释放、后台驻留、托盘恢复和开机启动设置验证通过；运行前后发行目录哈希不变。没有执行覆盖玩家安装目录的 Setup 向导测试。

8 个国内源的 latest 小文件完整哈希、ZIP 前 64 KiB、POE1 汉化 EXE 前 64 KiB，共 24 项内容检查通过。实际 Electron 测试还验证主源 503 后切换备用源，下载、安装与重启完成。大文件首段验证不等同于完整下载；正式升级测试另完整下载并校验了增量 ZIP。
