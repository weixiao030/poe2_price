# v0.9.3 发布验收

本版修复碑牌漏价及单侧行情不可用时整层价格被跳过的问题，补充旧快照、最低价、本地缓存和快照重试，修复日志跟随输出，并将软件更新切换为 GitHub 国内主备用源优先、ZOS 兜底。GitHub 提供 Setup、免安装 ZIP、专用增量 ZIP、签名清单和 SHA-256 清单；ZOS 本次只上传增量 ZIP 与签名清单。

## 碑牌与真实游戏文件

在当前游戏数据中核对 86 个不同 Mod、254 个底材词缀组合。最终发行引擎执行完整更新流程，当前双侧在线行情生成 254 组价格。魔法快照过期时继续使用同赛季旧价格；缺少中位价时采用有效最低价；网络异常沿用 HTTP 重试，快照异常从第一页最多重试 2 次；在线失败使用同来源、同赛季、同稀有度的上次成功快照。缺少单条行情时使用该条有效侧。

实际成功快照缓存后，模拟魔法、稀有 API 同时不可用，仍生成 254 组价格，全部词缀 CSD 与成功联网构建逐字节一致。缓存重新执行分页、赛季、稀有度及当前游戏词缀映射校验；不同快照汇率先逐侧换算为 D，再统一使用同一组显示汇率。回退类型、采样时间和重试原因均进入日志或报告。

总督“额外 1 个阿兹莫里魂灵”的网站报价存在，最终在线构建显示 `11C`，此次魔法查询范围准确，优先使用该侧。稀有查询可以匹配另一种魂灵词缀；当两侧均为同一个已知宽查询时保留网站参考报价，在 `query_scope_warning` 中说明；未知查询条件和不包含目标词缀的查询仍拒绝使用。

真实写入、官方启动及启动后回读结果：

- 20 项补丁资源与发行版内置 Python 构建结果逐字节一致。
- 254 组均有价格，12,964 项整数取值、简繁中文、共用稀有度映射检查通过。
- 3,647 行中文 CSD 括号平衡；最终补丁启动前后索引哈希一致，启动日志没有重新下载索引。
- 生产还原脚本执行两次：第一次恢复 4 项 DAT；第二次报告资源已是当前版本，无需写入。
- 还原后 13 项受检资源与官方 4.5.5.3 原始文件逐字节一致，碑牌继承引用恢复。还原后官方启动通过，索引仍一致。

严格还原会恢复官方繁中裂痕文本原有的多余右括号。逻辑还原会保留 GGPK 中不再引用的历史条目和空间，不代表整个 GGPK 字节或体积恢复出厂。这里验证资源写入、游戏启动和读回，未逐个登录角色打开所有物品提示框。

## 发行包与在线升级

原样正式 v0.9.2 的 355 项发行文件逐一通过保存基线的 SHA-256 校验。使用正式签名、正式增量 ZIP，在隔离副本通过本地 HTTPS 完成真实下载、校验、退出旧版、安装、自动重启及 v0.9.3 健康回执；最终 355 项目标文件回读一致，玩家自存文件保留。

增量包只包含 17 项变化文件及安装清单，大小为 110,256,859 字节。版本资源变化使完整 EXE 成为变化文件，因此增量包不是此前约 0.84 MB 的界面测试包。为避开存储中的历史测试对象，正式文件名为 `POE-Price-Patch-0.9.2-to-0.9.3-release-delta.zip`。

Setup 内的 356 项载荷与发行目录逐项一致。免安装 ZIP 在独立中文目录解压，355 项文件哈希一致，实际 EXE 启动、内置引擎释放、后台驻留、托盘恢复和开机启动设置验证通过；运行前后发行目录哈希不变。没有执行覆盖玩家安装目录的 Setup 向导测试。

8 个国内源的 latest 小文件完整哈希、ZIP 前 64 KiB、POE1 汉化 EXE 前 64 KiB，共 24 项内容检查通过。实际 Electron 测试还验证主源 503 后切换备用源，下载、安装与重启完成。大文件首段验证不等同于完整下载；正式升级测试另完整下载并校验了增量 ZIP。
