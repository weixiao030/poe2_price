# v0.9.4 过滤器兼容性修复

旧版碑牌价格把英文底材 `Breach Tablet` 改成 `[0.37D|Breach Tablet]`，导致过滤器 `BaseType == "Breach Tablet"` 无法找到完全匹配的基础类型。v0.9.4 保留英文原名，将名称价签限定在本地化名称表，并在安装前拒绝含价格标记的英文底材。

## 原因与修复

引入位置为提交 `05d6d9d` 中 `poe2_tablet_prices.py` 的英文分支：新增 `price_tablet_names(english_baseitems...)`，随后把结果放入 `data/balance/baseitemtypes.datc64`。后续版本继承了这段逻辑。原有测试也错误地要求英文表带价签，且使用中文模拟数据，未覆盖过滤器精确匹配。

现改为清除旧碑牌价签后仅保留必要的词缀模板引用。英文底表并非整文件恢复原版：8 类碑牌仍使用独立词缀模板，以显示各自的中文词缀价格；所有英文底材名称保持原版。通货与其他底材的英文价格标记也会被安装校验拒绝。关闭、跳过碑牌层及还原继续使用原有清理逻辑。

## 验证

- 实际游戏提取的 5,072 个英文底材名称中，仅 8 类碑牌与原版不同；修复后全部名称与当前官方基线一致。
- 英文 Words、EndgameMaps、Mods、Stats、Tags 与官方基线逐字节一致，未发现同类价签写入。
- 本机单资源修复仅改动 8 个名称指针并追加干净字符串，保留词缀引用及其他字段；20 项已安装补丁资源回读与预期一致。
- 9 个玩家过滤器逐文件 SHA-256 保持不变，因英文价签失去匹配的 59 条精确匹配规则重新具备原版名称。
- 使用真实游戏表和保存的行情响应重新构建 254 组碑牌词缀价格，生成的英文名称仍全部与原版一致。
- Python 全套 376 项通过；桌面测试 41 项通过；类型检查与生产构建通过。

以上过滤器验证基于游戏资源回读和规则名称对照，未自动登录角色执行游戏内加载操作。完整原始数据仅保存在本地忽略目录 `verification/filter-fix-20260922/`，不随发行包上传。

## 更新发行

旧版 v0.9.3 的 GitHub 发行与 ZOS 更新目标之间有 7 个文件哈希不同，因此 v0.9.4 使用完整更新包兼容两种 v0.9.3；原样 v0.9.2 继续使用严格校验基线的增量包。完整更新包不等同于免安装版，交由软件更新器下载并安装。

标签 CI 遇到已经准备好的 Release 时保留其资产和发布状态，防止重新构建的文件覆盖签名更新包所绑定的版本基线。完整安装版、免安装版、更新 ZIP 和签名清单按最终文件统一校验。

升级软件本身不会写入游戏。升级后关闭游戏并执行一次物价更新，以清除旧英文碑牌价签，再启动游戏加载原过滤器。
