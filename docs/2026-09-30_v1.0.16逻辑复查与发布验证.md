# v1.0.16 逻辑复查与发布验证

本次围绕更新、还原、行情构建、独立碑牌、后台任务及软件更新检查审阅源码，并执行项目测试与安装验证。前一轮玩家截图问题一并纳入本版。

## 修复

| 问题 | 修复行为 | 回归证据 |
| --- | --- | --- |
| 游戏更新使物理还原包失效后，清理迁移又写回碑牌价格 | 三处基线重建显式关闭碑牌名称与词缀价格 | 三个真实 PowerShell 参数调用执行 Python 清理，零网络请求且有效标记清零；两服真实资源离线对照 |
| 仅碑牌更新被普通行情或普通赛季目录故障阻断 | PowerShell 普通赛季解析与 Python 普通行情请求都只由普通通货/传奇范围触发 | 国服/国际服、自动/固定赛季、四种碑牌开关组合，普通范围仍解析并传递原赛季 |
| 核心重试删除 Words 参数后误用默认缓存，可能跨语言或写入损坏数据 | `--preserve-words` 完全跳过 Words 读取、清理和写入 | 真实核心参数转换，对正常其他语言缓存与损坏缓存均验证不写入 Words |
| C 单位名称价格未被识别，带价底板可能被视为干净 | 更新和还原检测覆盖 C/D/E | 从实际 DAT 生成价格后调用两个 PowerShell 检测器，覆盖 C、低于 1C、D、E 及干净名称 |
| POE1 汉化名称变了但结构没变时，仍复用旧还原底板 | 干净当前资源刷新逻辑基线；已有价格的连续更新保持干净备份 | 直接执行生产基线选择段，覆盖干净、本体价和 Words 价状态 |
| 更新镜像缓存当前版本时，提前结束检查而漏掉备用源新版 | 继续检查备用源；全部备用源失败仍保留已验证的当前版本结果 | 新版备用源、不可达备用源和无效签名用例 |
| 目录查询期间再次选择造成异步结果覆盖 | 查询期间禁用选择入口，并在状态层拒绝重入 | 慢查询期间第二次选择及运行任务期间选择用例 |

另修正桌面集成测试的定时器捕获：仅截获应用 `schedule` 创建的回调，避免误调用网络库定时器。赛季界面的紧凑布局检查等待窗口缩放与下拉框关闭完成，仍严格断言没有横向溢出。测试继续执行真实自动任务、取消、托盘关闭与重启行为；生产调度逻辑未为测试添加后门。

真实资源验证仅对提取副本和 WeGame 索引沙盒执行；两套真实游戏文件未改写。没有进行游戏内画面验证，也没有对玩家机器进行远程验证。早期复现及物理迁移指纹见 [还原基线迁移修复记录](2026-09-30_游戏更新后还原基线迁移修复.md)。

## 发布约束

版本统一为 `1.0.16`。发布前须通过 main 分支 `Build Desktop Release`，再推送 `v1.0.16` 标签，由标签工作流重新构建、验签并发布。GitHub 与 ZOS 使用同一份签名清单和安装文件；签名、哈希和旧版本不可覆盖规则继续保留。发布状态以 GitHub 工作流和 Release 为准。
